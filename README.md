# 🛒 Sistema de Gestión de Supermercado

## 📌 Descripción

Este proyecto consiste en el desarrollo de un sistema de gestión para un supermercado.
Permite administrar productos, clientes, empleados, compras, pagos e inventario de manera eficiente.

El objetivo es simular el funcionamiento básico de un supermercado utilizando Programación Orientada a Objetos (POO).

---

## 🎯 Funcionalidades principales

* 📦 Gestión de productos
* 🗂️ Clasificación por categorías
* 📊 Control de inventario
* 👤 Registro de clientes
* 👨‍💼 Gestión de empleados
* 🛍️ Registro de compras
* 💳 Procesamiento de pagos
* 🧾 Generación de facturas
* 🚚 Gestión de proveedores
* 🏪 Uso de caja registradora

---

## 🧱 Estructura del sistema (Clases)

El sistema está compuesto por las siguientes clases principales:

* **Supermercado**
* **Empleado**
* **Cliente**
* **Producto**
* **Categoría**
* **Inventario**
* **Proveedor**
* **Compra**
* **DetalleCompra**
* **Pago**
* **Factura**
* **CajaRegistradora**

---

## 🔗 Relaciones principales

* Un **Cliente** realiza una **Compra**
* Una **Compra** contiene varios **DetalleCompra**
* Cada **DetalleCompra** está asociado a un **Producto**
* Un **Producto** pertenece a una **Categoría**
* El **Inventario** gestiona los **Productos**
* Un **Proveedor** suministra **Productos**
* Una **Compra** genera una **Factura**
* Una **Compra** tiene un **Pago**
* Un **Empleado** opera una **CajaRegistradora**

---

## 🧪 Ejemplo de uso

1. Crear productos
2. Agregarlos al inventario
3. Registrar un cliente
4. Realizar una compra
5. Procesar el pago
6. Generar factura
